# BIP39 to 1Password for Raycast

Generate a 12- or 24-word BIP39 recovery phrase locally, derive EVM, Bitcoin
Native SegWit, and Solana addresses, and save everything directly to a
1Password Crypto Wallet item.

The recovery phrase is never shown in Raycast, copied to the clipboard, written
to disk, or included in process arguments. It is sent to `op item create`
through stdin and stored in a concealed 1Password field.

## Requirements

- macOS and Raycast
- 1Password 8 desktop app
- 1Password CLI (`op`)
- **1Password → Settings → Developer → Connect with 1Password CLI** enabled

## Raycast commands

### Preview Test Wallet

Raycast command: **BIP39 to 1Password → Preview Test Wallet**

This command is injected only by `npm run dev` and is excluded from production
builds. It provides a preview for testing wallet generation before connecting to
1Password. Opening the command immediately generates and displays the recovery
phrase, EVM address, Bitcoin Native SegWit address, Solana address, and their
derivation paths. The recovery phrase length is controlled by extension
preferences.

Preview copy shortcuts:

| Content         | Shortcut                                             |
| --------------- | ---------------------------------------------------- |
| Recovery phrase | <kbd>Command</kbd> + <kbd>Shift</kbd> + <kbd>M</kbd> |
| ETH/EVM address | <kbd>Command</kbd> + <kbd>Shift</kbd> + <kbd>E</kbd> |
| BTC address     | <kbd>Command</kbd> + <kbd>Shift</kbd> + <kbd>B</kbd> |
| SOL address     | <kbd>Command</kbd> + <kbd>Shift</kbd> + <kbd>L</kbd> |

This command never invokes the 1Password CLI. Because it displays the recovery
phrase in Raycast, every wallet generated by this command must be treated as a
disposable test wallet and must never hold real assets.

### Generate Wallet Seed

Raycast command: **BIP39 to 1Password → Generate Wallet Seed**

Generates a new wallet locally and saves it directly to 1Password. The command:

1. Checks that the 1Password CLI is installed and authenticated.
2. Loads the available 1Password vaults.
3. Generates a new 12- or 24-word BIP39 recovery phrase.
4. Derives the first EVM, Bitcoin Native SegWit, and Solana addresses.
5. Creates a 1Password Crypto Wallet item containing the concealed recovery
   phrase, public addresses, derivation paths, and safety notes.

The command form contains:

| Field                     | Description                                                         |
| ------------------------- | ------------------------------------------------------------------- |
| **Item Title**            | Name of the new item in 1Password. Defaults to `My Wallet Seed v1`. |
| **1Password Vault**       | Selects the vault in which the item will be created.                |
| **Security Confirmation** | Must be checked before a wallet can be generated.                   |

Available actions:

| View                 | Action                             | Description                                                 |
| -------------------- | ---------------------------------- | ----------------------------------------------------------- |
| Wallet form          | **Generate and Save to 1Password** | Generates the recovery phrase and saves the wallet item.    |
| Saved result         | **Open in 1Password**              | Opens the newly created item in the 1Password desktop app.  |
| Setup error          | **Retry**                          | Checks the CLI, authentication, and vault list again.       |
| Missing CLI          | **Open Extension Preferences**     | Opens the setting for a custom absolute `op` CLI path.      |
| Authentication error | **Open 1Password Settings**        | Opens 1Password settings so CLI integration can be enabled. |

The result view displays only the saved item name, vault, public addresses, and
derivation paths. It never displays the recovery phrase.

## Extension preferences

| Preference                 | Description                                                                          |
| -------------------------- | ------------------------------------------------------------------------------------ |
| **Recovery Phrase Length** | Generates 12 words by default. Can be changed to 24 words for both Raycast commands. |
| **1Password CLI Path**     | Optional absolute path to the `op` binary.                                           |

## Development

```bash
npm install
npm test
npm run lint
npm run build
npm run dev
```

The extension looks for `op` at `/opt/homebrew/bin/op` and
`/usr/local/bin/op`. A custom absolute path can be set in extension preferences.

## Security model

- 1Password readiness is checked before a recovery phrase is generated.
- Recovery phrases exist only in process memory until `op` finishes.
- The 1Password JSON template is passed over stdin.
- Only public addresses and 1Password item metadata appear in the result view.
- No transaction or message signing is implemented.
